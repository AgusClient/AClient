What's New in Clientx30 (Quick Summary)
== Clientx30 新功能一览

* Race Stats Overlay + Log:
== * 比賽统计悬浮窗 + 歷史归档:

Live HUD stats (Freezes, Saves, Lasts, Efficiency) and auto-saved run time.
== 实时顯示冰冻、营救、遗留、救援效率，并自动记录通关耗时。

* Fast Practice (Ghost Mode):
== * 快速練習 (幽灵模式):

Practice any map part with /tp, /tc, /invincible without leaving your real run.
== 使用 /tp、/tc、/invincible 自由練習关卡，无需中断真实比賽。

* Independent Fast Input:
== * 独立输入预判 (Fast Input):

Set separate visual prediction ms for yourself (Amount) and others (Others Amount).
== 可分别调整自己 (Amount) 与其他玩家 (Others Amount) 的预判毫秒数。

* Auto Team Lock (up to 5m):
== * 自动隊伍锁定 (最高5分钟):

Automatically locks team (/lock 1) after configured delay when joining.
== 进队后按照設置的延迟自动执行 /lock 1 锁定隊伍。

* Bulk Invites:
== * 批量隊伍邀请:

Use /invite all or /invite friends with anti-flood queue and Tab auto-complete.
== 支持 /invite all 与 /invite friends，具备防刷屏队列及 Tab 自动补全。

* Active Vulkan Renderer:
== * 原生 Vulkan 渲染后端:

Compiled SPIR-V shaders included for smoother frame rates and lower CPU usage.
== 内置编译好的 SPIR-V 着色器，帧率更稳且大幅降低 CPU 占用。
